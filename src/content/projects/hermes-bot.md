## 简介

把 Hermes Agent 接到个人微信上 —— 你发条消息就能让它跑命令、写代码、查资料。

## 特点

- iLink Bot API 接入，零基础设施
- 长轮询，毫秒级响应
- 媒体、文件、Markdown 全部支持
- 备用微信账号专用

## 怎么用

扫码登录、配置好、给 bot 发消息，剩下 Hermes 帮你搞定。
