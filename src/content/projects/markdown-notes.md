## 简介

一个命令行工具，把 `~/notes/` 里的 markdown 文件组织成可搜索的知识库。

## 命令

- `notes new` — 新建一篇
- `notes search <keyword>` — 全文搜索
- `notes link <a> <b>` — 在两篇笔记间加双向链接
- `notes serve` — 启动本地 Web 端
